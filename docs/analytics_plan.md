# CSU IS Career Hub – Analytics Plan

Author: Madhav Bhalani

## Purpose
This document defines how we will track user activity and measure the performance of the CSU IS Career Hub platform.

---

## Why Analytics is Important

Analytics helps us understand:
- What users are doing on the website
- Which features are useful
- Where users face issues

---

## Key Metrics to Track

1. Page Views  
Track which pages users visit the most  

2. Job Clicks  
Track which job postings users click  

3. Certification Clicks  
Track which certifications users explore  

4. Search Usage  
Track what users search for  

5. Time Spent  
Measure how long users stay on pages  

---

## Events to Track

- User clicks on a job posting  
- User clicks on a certification  
- User filters jobs  
- User navigates between pages  

---

## Tools (Future Implementation)

- Google Analytics  
- Firebase Analytics  
- Custom tracking using backend API  

---

## Example Use Case

If many users click “Data Analyst” jobs:
→ Recommend SQL and Power BI certifications  

---

## Next Steps

- Integrate analytics tool (Google Analytics)
- Track user events
- Use data to improve recommendations

---

## Summary

Analytics will help improve the platform by understanding user behavior and making better recommendations for students.
