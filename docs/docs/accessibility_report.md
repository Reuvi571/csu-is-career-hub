# CSU IS Career Hub – Accessibility & Lighthouse Report

Author: Madhav Bhalani

## Purpose
This document evaluates the accessibility and performance of the CSU IS Career Hub using Lighthouse.

---

## Lighthouse Audit (Sample)

Page Tested: Home Page (Prototype)

### Scores:
- Performance: 85
- Accessibility: 90
- Best Practices: 88
- SEO: 92

---

## Key Accessibility Issues Found

1. Missing alt text on images  
Fix: Add descriptive alt text  

2. Low color contrast  
Fix: Improve contrast between text and background  

3. Buttons without labels  
Fix: Add clear labels for screen readers  

---

## Improvements Made / Suggested

- Add alt text to all images  
- Improve color contrast for readability  
- Ensure all buttons and links have labels  
- Use proper heading structure (H1, H2, etc.)

---

## Summary

Accessibility improvements ensure the platform is usable for all users, including those with disabilities. Lighthouse helps identify key issues and track improvements.
